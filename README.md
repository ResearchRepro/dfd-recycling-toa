# DfD–recycling patent opportunity analysis

Reproducibility materials for the manuscript **From Disassembly Functions to Recycling Opportunities: Cross-Field Patent Analytics for Design for Disassembly and Recyclability**.

## Contents
- `notebooks/Recycle_TOA_Colab_Resumable_V2.ipynb`: original analysis pipeline (when available).
- `notebooks/Reviewer_Revision_Validation_Colab.ipynb`: reviewer-response audit, annotation templates, and sensitivity analyses (when available).
- `results/`: selected aggregate outputs actually generated by the audit. Missing analyses are not implied to have been completed.
- `requirements.txt` and `runtime.json`: environment information collected during export.

## Reproduction
1. Use Google Colab or a Python environment with the specified requirements.
2. Supply legally accessible Lens patent exports and/or the saved V4 results to the original notebook's configured Google Drive project directory.
3. Run the original analysis notebook, then the reviewer-validation notebook in order.
4. For independent classification evaluation, obtain expert labels and adjudicate them before reporting precision, recall, and F1.
5. Recheck search dates, queries, jurisdiction, source-language provenance, and alternative scoring/cluster settings against original records.

## Data restrictions and interpretation
Raw Lens exports, patent abstracts/claims, personal information, and incomplete expert annotations are not included here. Access to original patent data depends on source availability and redistribution rights. Diagnostic parameter sweeps are not substitutes for independent expert validation. The repository does not establish that the identified opportunities improve real-world recyclability.
